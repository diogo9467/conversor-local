MuPDF / Extract 1.28.5
Copyright Artifex Software, Inc. and contributors. AGPL-3.0-or-later.
Android Java API from the official AAR; JNI compiled from pinned source with
NDK 27.2.12479018. Checksums and source URLs in engine-lock.json.
Source: https://github.com/ArtifexSoftware/mupdf/tree/1.28.5
Source archive: https://mupdf.com/downloads/archive/mupdf-1.28.5-source.tar.gz
The native MuPDF DOCX writer performs layout reconstruction, table recognition
and image extraction. This application does not implement an alternative layout engine.
The source patch in tools/patch_mupdf.py fixes PNG image ownership/geometry,
retains image relations across pages, emits required OOXML image dimensions and
integer font sizes, and matches ZIP local/central flags and Deflate version.

AndroidX / Jetpack Compose: Apache-2.0 (Android Open Source Project).
Kotlin and kotlinx.coroutines: Apache-2.0 (JetBrains and contributors).
The empty PPTX template was generated for this application with python-pptx;
it contains no personal content. Android PdfRenderer is part of Android.

No engine is downloaded by the Android app. This build declares no INTERNET or
all-files-access permission. Licenses are included in assets/licenses/.
